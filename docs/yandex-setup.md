# Яндекс Карты и оформление

Сайт использует JavaScript API Яндекс Карт v3. При наличии ключа он загружает настоящую схему с метками, поиском, фильтрами и карточками клубов. Цвет схемы меняется штатным параметром SDK вместе с темой сайта. Смена темы не пересоздаёт карту. Логотип и авторские подписи поставщика сохраняются.

## Ключ и публикация

1. В [кабинете разработчика Яндекса](https://developer.tech.yandex.ru/) нужен ключ JavaScript API, совместимый с v3. Условия и лимиты задаёт Яндекс: получение ключа не гарантирует бесплатный тариф. Проект сам не подключает платный тариф.
2. Ограничьте браузерный ключ доменом `leethoof1.github.io`. Для локальной проверки при необходимости разрешите localhost.
3. На GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Имя — **YANDEX_MAPS_API_KEY**, значение — ваш ключ. Значение не нужно добавлять в исходники или чат.
4. Перенесите изменения в `main`. Workflow проверяет наличие секрета и подставляет его в сборку как `VITE_YANDEX_MAPS_API_KEY`. После замены значения повторите workflow: опубликованный JavaScript не читает GitHub secrets при открытии страницы.
5. Для локальной разработки создайте игнорируемый `.env.local` с `VITE_YANDEX_MAPS_API_KEY=...` и перезапустите Vite. Шаблон без значения — `.env.example`.

Ключ браузерного API попадает в публичную сборку. GitHub secret защищает исходники и настройки сборки, но не делает клиентский ключ серверным секретом. Ограничение использования задаётся в кабинете Яндекса доменом сайта и разрешёнными API.

Для локальной разработки без ключа остаётся OpenStreetMap. Если загрузка API Яндекса завершилась ошибкой, посетитель может повторить её или открыть резервную OSM; каталог клубов продолжает работать.

## Выбор темы

На компьютере в шапке три отдельные кнопки: «Светлая», «Тёмная», «Авто». Одно нажатие меняет оформление сайта и схемы Яндекса. На телефоне сохранён прежний компактный нативный выбор. В «Авто» цвет следует настройкам устройства; ручной выбор сохраняется локально.

## Проверка и ограничения

`npm run build` проверяет типы и сборку. `npm test` выполняет 50 браузерных проверок. Порты 5173 и 5175 отделяют OSM без ключа от контракта Yandex SDK с явно фиктивным тестовым ключом. Все вызовы Яндекса в этих тестах перехватываются: они проверяют наш код без платных запросов, а не доступность серверов или авторизацию настоящего ключа.

Реальный ключ пользователь настроил в GitHub; в облачный процесс он не передавался. Первую загрузку картографии и авторизацию необходимо подтвердить на опубликованном сайте после слияния и успешного workflow.

Координаты части клубов по-прежнему предварительные. Подключение Яндекса само по себе не выполняет геокодирование и не делает эти координаты проверенными.
