# Проверка координат 22 мест

`npm run geocode` выполнил 30 запросов Nominatim с интервалом не менее 1,1 секунды. Для 19 мест совпали улица и номер дома с корпусом внутри заданной области Санкт-Петербурга. Все результаты проверены по `matchedAddress`; координаты и ссылки на объекты сохранены в `src/geocoded-places.json`.

Три несовпадения проверены отдельно:

| Место | Проверка | Координаты (широта, долгота) |
| --- | --- | --- |
| Романтики | [OSM way 31007163](https://www.openstreetmap.org/way/31007163): Ленинский проспект, **158 к2 литА**. Улица и корпус совпадают; координаты получены через Nominatim lookup. Дом 158 без корпуса и трансформаторная подстанция с литерой Т исключены. | 59.8532160, 30.2992693 |
| Космос | [OSM way 53357426](https://www.openstreetmap.org/way/53357426): «Творческое пространство Космос», Московский проспект, **174**. В адресе каталога — **174А**, но совпадают название, телефон **+7 (812) 417-34-36** и группа **kosmos_pmk**. Координаты приняты вручную по идентичности учреждения; адрес каталога сохранён. | 59.8769204, 30.3223321 |
| Октябрь | [Яндекс Карты, организация 1001846110](https://yandex.ru/maps/org/molodezhny_klub_oktyabr/1001846110/): «Молодежный клуб Октябрь», **Пулковская улица, 11к1**, телефон **+7 (812) 417-32-31**. Совпадают название, точный корпус и телефон. Дом 11 из OSM без корпуса не принимался как точное совпадение. | 59.838449, 30.348067 |

Для ручных результатов сохранено поле `reviewNote`. Повторный запуск использует кэш при совпадении исходного адреса и не затирает эти результаты. Посетители сайта не обращаются к геокодеру.

Все 22 метки используют сверенные координаты, без пунктирного признака предварительного положения. Карточка показывает фактический источник точки: OpenStreetMap / Nominatim или Яндекс Карты. Результаты привязаны к зданиям или карточке учреждения; точное положение входа и актуальность работы клуба этим не подтверждаются.
